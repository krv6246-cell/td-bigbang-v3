# Time Density: Big Bang

**Time Density: Big Bang** — это медитативная Android-игра, написанная на Kotlin с использованием Jetpack Compose. В ней вы берете на себя роль оператора, управляющего плотностью времени и удерживающего вселенную от энтропийного коллапса.

## Особенности
* **Космическая визуализация:** Неоновая туманность, звёздное поле, гравитационная сетка и частицы реагируют на состояние вселенной.
* **Процедурный саундтрек:** `BigBangAudioEngine` синтезирует эмбиент и эффекты в реальном времени; в Point Zero включается отдельный резонансный синтезатор.
* **Продвинутая тактильная отдача:** Использование вибрации устройства (`HapticManager`) для передачи ощущения каждого игрового события.
* **Три уровня эволюции:**
  1. *Big Bang:* Фаза расширения. Стабилизация квантов через тапы.
  2. *Quasar Dynamics:* Управление релятивистскими джетами и гравитационными якорями.
  3. *Point Zero:* Синхронизация резонансных частот через точный тюнинг.
* **Оптимизированный жизненный цикл:** Безопасное управление корутинами и ресурсоемкими потоками аудио для экономии батареи устройства.

## Технологический стек
* Android SDK (Min API 24+)
* Kotlin
* Jetpack Compose (UI)
* Coroutines / StateFlow (Управление состоянием)
* AudioTrack (Низкоуровневый аудио-синтез)

## Управление
* **Big Bang и Quasar:** нажимайте на светящиеся кванты, удерживайте палец в любой точке для замедления энтропии.
* **Point Zero:** перетаскивайте палец вертикально, чтобы совпасть с частотой, и удерживайте резонанс.

## Запуск и просмотр без Android Studio
Это нативное Android-приложение, поэтому браузерный просмотр без отдельной веб-версии не предусмотрен. Android Studio не обязательна: установите Android SDK и Gradle, затем соберите APK и установите его на Android-устройство через USB debugging:

```bash
gradle :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Для просмотра на компьютере можно запустить Android Emulator из Android SDK и установить APK той же командой. На реальном устройстве лучше проверяются звук и вибрация. В репозитории сейчас нет Gradle Wrapper, поэтому команда `gradle` требует отдельно установленный Gradle.
